# StudyOS v0.51.0 Desktop Beta

StudyOS v0.51.0 adds the first downloadable Windows desktop distribution.

## Highlights

- Windows NSIS installer
- Portable Windows executable
- Bundled production Next.js UI
- Bundled local FastAPI backend executable
- Local SQLite database and upload storage under Windows AppData
- Sandboxed Electron renderer with Node integration disabled
- Context isolation + renderer sandboxing
- Navigation/window restrictions for untrusted destinations
- First-run StudyOS server connection screen
- HTTPS required for remote StudyOS servers
- Local reverse proxy keeps existing same-origin API/cookie behavior
- Automated Windows packaging in GitHub Actions
- Published GitHub Releases automatically receive generated EXE assets

## Distribution model

The desktop application contains both the StudyOS web interface and a local StudyOS backend.
Normal Windows users can install and run it without Python, Node, Docker, PostgreSQL, or a
server URL. The app starts its backend on private loopback, persists data in Windows AppData,
and keeps hosted/cloud backend mode available as an optional configuration.

## Windows beta limitation

The current beta binaries are not Authenticode-signed. Microsoft SmartScreen may therefore
show an unknown-publisher warning. Code signing is required before broad consumer rollout.

## Build verification

The initial Windows packaging workflow successfully produced the NSIS + portable build and
uploaded the `studyos-windows` Actions artifact.

Electron follows the upstream security recommendations used for this shell: no Node.js
integration in remote/app content, context isolation enabled, renderer sandboxing enabled,
permission requests constrained, and navigation/new-window behavior restricted.
