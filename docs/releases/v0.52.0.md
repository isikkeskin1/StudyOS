# StudyOS v0.52.0 — Distribution, Updates & Institutional Courses

**StudyOS now behaves like a real desktop product — and universities can be curated once instead of rebuilt by every student.**

v0.52.0 is the largest distribution-focused StudyOS beta update so far. It adds automatic desktop updates, faster Windows startup, a branded updater experience, and the foundation for admin-curated institutional courses built from public and authorized teaching material.

## Highlights

### Automatic Windows updates

Installed StudyOS builds can now:

- check GitHub Releases for newer versions;
- download updates in the background;
- show a StudyOS-branded progress window with percentage and download speed;
- offer **Restart & update** when the new version is ready;
- install a downloaded update when StudyOS exits.

The release pipeline now publishes and verifies the updater metadata required by Electron/NSIS, including `latest.yml` and blockmaps.

**Important:** v0.52.0 is the bootstrap updater release. Pre-v0.52 installs must be upgraded manually once. After that, installed builds can update through StudyOS.

### Faster desktop startup

StudyOS no longer waits for each local service one after another.

The bundled FastAPI backend and Next.js shell now start in parallel behind an immediate StudyOS splash screen. The real app window replaces the splash as soon as the local runtime is ready.

### Institutional Course Catalog

Admins can build reusable master courses for institutions such as **Politecnico di Torino**.

A curated course can include:

- official syllabus/course pages;
- lecture notes and slides;
- exercise sheets;
- formula sheets;
- past exams;
- solutions;
- exam information;
- any private material the admin is authorized to provide.

Admins can review discovered sources, approve/reject them, import approved material, process the master course once, publish it, and assign it directly to a user account.

### Politecnico di Torino source discovery

POLITO courses get an official-source helper. With the course code, StudyOS can build official Teaching Portal seeds and discover relevant official teaching/curriculum surfaces without relying on third-party search indexes.

### Better exam ingestion

StudyOS now rejects numbered administrative blocks such as exam rules, device restrictions and anti-cheating instructions instead of mistakenly turning them into diagnostic questions.

## Desktop reliability

This release also includes the cumulative v0.51 desktop fixes:

- real startup diagnostics;
- AppData desktop logs;
- local-runtime retry;
- validation of hosted StudyOS servers;
- cleanup of partial backend/web processes;
- explicit packaged Next.js runtime dependencies;
- packaged-app smoke testing against real API traffic.

## Windows downloads

### Recommended

**StudyOS-0.52.0-Windows-x64-Setup.exe**

Use the installer if you want automatic updates.

### Portable

**StudyOS-0.52.0-Windows-x64-Portable.exe**

Runs without installation. Portable mode intentionally does not self-update.

## Windows SmartScreen

StudyOS beta releases may still be unsigned.

Windows can therefore show **Unknown publisher** or **Windows protected your PC**. The build pipeline is now code-signing ready, but there is no legitimate software-only bypass for Windows publisher trust. Trusted Authenticode signing or Store/MSIX distribution is the supported solution.

## For administrators

Configure admin accounts with:

```env
STUDYOS_ADMIN_EMAILS=admin@example.com
```

Then open **Admin catalog** in StudyOS to create institutional master courses, discover sources, review/import them, publish courses and assign them by student email.

## Upgrade path

If you are currently on v0.51.x, install v0.52.0 manually once.

After that:

```text
Publish new StudyOS release
        ↓
Installed StudyOS checks GitHub
        ↓
Downloads update
        ↓
Restart & update
        ↓
Done
```
